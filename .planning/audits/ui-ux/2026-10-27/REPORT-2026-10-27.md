## Root causes confirmed by measurement

- Header shift `/` → `/genes`: no `scrollbar-gutter: stable`; the 15px scrollbar disappears while `/genes` loads (docH 900 < viewport), the centered header widens 1425→1440px and the nav moves ~7px.
- Default cursor on buttons: Tailwind v4 preflight sets `button { cursor: default }` and no base rule restores it.
- Colour drift: 185 raw palette classes in 37 files and 339 hex/rgb literals; source, classification and status colour maps defined in 6+ places each.
