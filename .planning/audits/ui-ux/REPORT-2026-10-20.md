# UI/UX audit: 2026-10-20

- **Commit:** `2c6bfe9` (v0.5.2)
- **Data:** local hybrid stack with 5,184 genes
- **Method:** Impeccable critique + audit, Lighthouse 12.8.2 on a production build, Playwright CLS and flicker measurements, and axe. Three expert reviewers covered disjoint groups of views (rubric in [README.md](README.md)).
- **Saved data:** measured baseline in [`runs/2026-10-20-baseline.json`](runs/2026-10-20-baseline.json); expert scores in [`scores-2026-10-20.json`](scores-2026-10-20.json).
- **Re-running:** see [README.md](README.md).

## Summary

Mean expert score is **61/100** across 27 views. The lowest are the gene list
and the admin home (50); the highest are forgot-password (76) and the 404 page (74).

The design base is sound: shadcn-vue throughout, visible focus rings, filter
state in the URL, and a solid dark palette. Most of the low scores come from
defects, not taste:

- controls that silently do nothing
- production serving an empty page to gzip clients
- admin pages that are blank on direct load
- one CSS-loading option that causes most of the layout shift

## What works

- Visible focus rings and URL-driven filter state
- A Home skeleton, and the evidence accordion on gene detail
- The citation block
- The MCP documentation copy
- Real WebSocket progress in admin
- Self-delete blocked in both the UI and the API
- Clear login validation
- A dark theme that passes contrast once it is applied consistently

## Not covered

- Screen-reader output
- Touch gestures on the network graph
- Colorblind simulation in dark mode
- Admin create, restore and edit dialogs (judged from source only; no mutating clicks)
- Alias search (all aliases in the local database are empty)
